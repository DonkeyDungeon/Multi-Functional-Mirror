# Multi-Functional Mirror（多功能镜子）— 0.1.0-rc.1

维护者：DonkeyDungeon  
支持邮箱：kongtiaoxukun@gmail.com

## 快速开始

先在 Unity 项目中安装、配置所需渲染管线，再导入对应管线的资源包。没有安装 HDRP 的工程不要导入 HDRP Shader。各管线包共用核心脚本和贴图 GUID，不附带 Unity 官方管线源码。

打开 `Samples/管线/MirrorShowcase` 示例场景；从 `Prefabs/管线` 拖入 SquareMirror（方镜）、RoundMirror（圆镜）或 Puddle（水坑）。预制体的反射正面是局部 +Z，选中后青色箭头显示方向。水坑已旋转至朝上。

组件负责反射拍摄，材质负责表面效果。相机在背面时不生成反射。其他本工具的镜面不会出现在反射中，以避免无限递归。

## 组件参数

| 参数 | 作用 |
|---|---|
| Resolution | 反射贴图边长，64–4096；建议先用 512。像素和显存开销随边长平方增长。 |
| Reflection Layers | 反射层，与观察相机的可见层取交集。 |
| Update Every Frames | 1 每帧更新；更高值节省渲染次数，但移动时反射会滞后。 |
| Far Distance | 反射相机距离限制；斜截面投影可能影响实际远裁剪效果，精准排除对象请使用层。 |
| Local Normal | 局部正面方向，随包网格用 +Z；支持非均匀缩放的法线变换。 |
| Clip Offset | 镜面附近裁剪偏移；过大会裁掉附近物体。 |
| Reflect Skybox / Background Color | 天空盒或指定背景色。 |
| Transparent Background | 使用捕获画面的透明度，须结合对应管线验收结果使用。 |
| Scene View Preview | 编辑模式下，随 Scene 视图重绘更新反射。 |

## 材质参数

Mirror Color 对最终混合结果染色一次，Alpha 控制表面透明度。Normal Map 和 Distortion Strength 控制画面扭曲。

Scratch Mask 使用绿通道，Scratch Intensity 控制浅色划痕和依赖法线的微小扰动。它不是物理粗糙反射，也不是反射模糊；即使法线为平面，划痕颜色仍可见。Water Stain Mask 使用透明通道，Water Stain Strength 独立控制水渍。

Puddle Mode 启用程序化水坑轮廓。Threshold 控制覆盖面积，Edge Softness 控制边缘，Scale、Warp、Detail、Seed 控制形状。Water Ripples 及其 Scale、Speed、Strength 控制水波扰动，不包含已移除的雨点系统。

## 已知限制与排错

仅用于平面；不支持镜子互相反射。XR/双眼摄像机会跳过。移动端、主机、光追、摄像机堆叠、自定义 Renderer、第三方后处理尚未认证。URP 反射采用默认 Renderer，不复制观察相机后处理；HDRP 使用原生渲染流程，不含 HS2 Graphics 桥接或额外皮肤 SSS 开关。

反射在较晚的 LateUpdate 中、SRP 渲染循环之外更新。相机控制器应在执行顺序 10000 之前完成移动，特殊控制器可在移动后、正式渲染前调用 RenderForCamera。每个镜面/观察相机组合独占贴图和禁用相机。当前相机缺少有效捕获或组件处于禁用状态时，随包 Shader 会将镜面渲染为透明。组件只写入 Renderer PropertyBlock 中以 `_DDMirror` 开头的专用属性。使用按材质索引设置 PropertyBlock 的项目需自行合并这些反射属性。

粉色：确认管线、Shader 和 Console。空白：确认正面方向、反射层和相机视野。划痕无效：确认贴图不是空资源、使用绿通道且强度大于零。性能下降：先降低分辨率、镜子数量和反射层，再考虑降低更新频率。
